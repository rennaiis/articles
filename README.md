Чтобы запустить приложение, выполните следующие шаги: 
1) Eсли на Вашем компьютере не установлены Node.js и PostgreSQL, установите их
2) Отредактируйте переменные окружения. 
- в файле backend/.env введите своё имя пользователя для PostgreSQL и пароль. Введённый Вами пользователь должен обладать правами на создание, удаление, изменение таблиц, а так же на чтение и запись данных. 
- также можете изменить порт для запуска приложения в переменной PORT в файле backend/.env (по умолчанию 3000). Но если Вы его изменили, отредактируйте переменную VUE_APP_API_ADRESS в файле frontend/.env, заменив порт в конце адреса на выбранный Вами, иначе не получится осуществить связь между внешней и внутренней частями приложения.
3) Установите необходимые пакеты, если их у Вас ещё нет: 
- в папку /backend: 
cd backend
npm install
- в папку /frontend:
cd frontend
npm install 
4) Создайте базу данных:
- Перейдите в папку /backend (cd backend)
- Введите в командной строке npx sequelize-cli db:create
- для создания таблиц в базе данных введите npx sequelize-cli db:migrate
- для загрузки сидов введите npx sequelize-cli db:seed:all
5) для запуска приложения введите в командную строку npm run start в корне приложения
(Если не установлен npm-run-all, то сначала его необходимо установить с помощью строки npm install -g npm-run-all)
